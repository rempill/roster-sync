RosterSync - distributie sincronizata cu proiectul revamp

Pastreaza branch1, branch2, branch3, branch4, branch5 si branch6 in acelasi folder.
Necesita Docker Desktop cu containere Linux.
Din folderul care contine cele sase directoare:
  docker compose -f branch6/compose.yml up --build -d --wait --wait-timeout 180
Deschide http://localhost:3000
Cont: alex@stud.ubbcluj.ro / Demo12345!
Mara, lider StudyFlow: mara@stud.ubbcluj.ro / Demo12345!
Oprire fara stergerea datelor:
  docker compose -f branch6/compose.yml down

branch1: matching FastAPI si teste
branch2: calendar ICS, intersectia disponibilitatii si teste
branch3: NestJS, Prisma, conturi, echipe si tranzactii
branch4: Socket.io autentificat si notificari private
branch5: frontend-ul revamp Next.js
branch6: Compose, teste de integrare/browser si CI

Testare backend:
  docker compose -f branch6/compose.yml exec -T matching python -m unittest -v test_matching test_scheduling
  docker compose -f branch6/compose.yml exec -T core npm test
  docker compose -f branch6/compose.yml exec -T core node checks/integration.mjs
Testare browser, cu Node.js 22 instalat:
  npm ci --prefix branch6
  node branch6/node_modules/playwright/cli.js install chromium --only-shell
  node branch6/checks/browser.mjs

Datele si secretele demo sunt pentru testare locala. SSO nu este implementat.
Aceste directoare formeaza o distributie comuna, nu sase proiecte independente.
Nu copia Dockerfile-urile ca atare in apps/: caile COPY sunt pentru aceasta distributie.
Workflow-ul activ al ZIP-ului este .github/workflows/demo.yml, identic cu branch6/ci.yml.
